# Gizmo

Gizmo is a library for writing JMAP servers in Go.  It handles the protocol,
storage, authentication, and push, and leaves the application to say what its
data is.

- **[The manual](manual/index.md)** documents each of Gizmo's packages,
  from the doc comments in its source.
- **[Learning Go from Gizmo](learning/index.md)** is a booklet that teaches Go
  by way of Gizmo and the servers built on it.

The source is [on GitHub](https://github.com/rjbs/gizmo).
